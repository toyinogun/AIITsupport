When you sign in to Microsoft 365 away from the office, you are asked for a code.

To receive the code by text message:

1. Go to your Microsoft account security page.
2. Choose **Add sign in method**, then **Phone**.
3. Enter your mobile number and choose **Text me a code**.
4. Type the code you receive.

From then on every sign in code arrives as a text message.
